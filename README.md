# Домика - адаптивный магазин предметов для дома

Учебный демонстрационный проект для контрольной работы №3 «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## О проекте

«Домика» - статичный многостраничный магазин товаров для дома. Реализованы главная, каталог, динамически заполняемая карточка товара, форма заказа и контакты. Проект работает без библиотек и без backend: формы демонстрируют клиентскую валидацию, а счётчик учебной корзины хранится в `localStorage` браузера.

## Адаптивные решения

- В каждой странице есть `meta viewport`; оба CSS-файла подключены, `responsive.css` - после `style.css`.
- Базовые правила рассчитаны на узкий экран (Mobile First); расширения расположены в `css/responsive.css`.
- Контрольные точки в стилях: 480, 700, 768, 1024 и 1440 px.
- Flexbox используется в шапке, навигации, кнопках и группах элементов; CSS Grid - в каталоге, карточках, формах и двухколоночных блоках.
- На телефоне навигация открывается отдельной кнопкой с `aria-expanded`; меню закрывается по Escape, по выбору ссылки и клику вне меню.
- Каталог фильтруется по категориям, цене и поисковому запросу; есть сортировка и сброс фильтров. Фильтр категории можно открыть ссылкой вида `catalog.html?category=decor`.
- Карточка товара переключает данные и изображения по адресу `product.html?item=vase` (поддерживаются `vase`, `throw`, `lamp`, `chair`, `mug`, `tray`). На мобильном характеристики показаны в виде карточек, на широком экране - семантической таблицей.
- Для изображений заданы `max-width: 100%`, `width`/`height`, `loading="lazy"` для изображений ниже первого экрана и `srcset`/`sizes`. В `<picture>` есть WebP и JPG-варианты. Все ресурсы локальные - сайт работает без CDN и внешних шрифтов.
- Формы на телефоне идут в одну колонку; на широком экране часть полей располагается в две колонки. Размеры полей и кнопок удобны для касания.
- Таблица не вызывает боковую прокрутку всей страницы: на мобильном применяется компактное карточное представление характеристик.

## Доступность

- На каждой странице есть один главный заголовок `h1`, семантические `header`, `nav`, `main`, `footer` и ссылка пропуска к основному содержимому.
- Для интерактивных элементов предусмотрен видимый `:focus-visible`; меню можно открыть с клавиатуры и закрыть клавишей Escape.
- Кнопки, ссылки и поля форм используются по назначению; у полей есть явные `label`, у групп вариантов - `fieldset` и `legend`.
- Контентные изображения имеют осмысленные `alt`; декоративные SVG скрыты от скринридеров.
- Цвета текста и фона выбраны с контрастом, анимации отключаются при `prefers-reduced-motion`.
- Для статуса корзины, результатов фильтрации и сообщений формы предусмотрены live regions. ARIA используется только там, где она проясняет назначение или состояние.

## Запуск локально

Откройте папку проекта в терминале и запустите простой сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Самостоятельные доработки в примере

- мобильное меню с закрытием по Escape и клику вне меню;
- поиск, фильтры и сортировка каталога;
- карточка товара с динамическими данными из query-параметра;
- мобильное карточное представление характеристик;
- локальные адаптивные WebP/JPG-изображения;
- сохранение счётчика корзины между страницами;
- доступные статусы отправки учебных форм.
